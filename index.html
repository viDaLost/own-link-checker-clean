Own Link Checker

Генерирует варианты ссылок по шаблону и показывает, какие из твоих ссылок открываются. Есть лимит скорости, остановка проверки и экспорт только рабочих результатов.

Настройка

Шаблон использует {num} для числа и {letters} для буквенного кода.

Пример даст ссылку вида https://telegra.ph/ZZH-23-20-om-12-10
Можно через пробел, запятую или с новой строки.
Например, алфавит om и длина 2 создаст oo, om, mo, mm.
Для Vercel оставь /api/check. Для другого сервера укажи полный адрес.
Для telegra.ph прямой браузерный режим может показать CORS. Тогда ставь проект на Vercel/сервер и используй режим backend.

Как это работает

Сначала приложение создаёт список из шаблона, например https://telegra.ph/ZZH-23-{num}-{letters}-12-10. Потом проверяет каждую ссылку и показывает статус.

Рабочая — сервер вернул HTTP 200–399. Не найдена — HTTP 404/410. CORS означает, что браузеру запрещено читать ответ сайта. Для таких сайтов нужен backend API из архива.

В backend есть ограничение: по умолчанию он проверяет только домены из переменной ALLOWED_HOSTS. Для Telegra.ph поставь ALLOWED_HOSTS=telegra.ph.
